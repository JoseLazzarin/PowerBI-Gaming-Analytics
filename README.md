# 🎮 Gaming Analytics: Dashboard de Performance & UX

## 📌 Descripción del Proyecto
Este proyecto analiza más de 16,000 registros de la industria de los videojuegos para explorar las relaciones entre la **Calidad Gráfica**, la **Jugabilidad**, la **Duración** y la **Innovación** sobre la **Valoración Promedio de los Usuarios**.

El informe fue diseñado bajo estándares de interfaz de usuario modernos (UI/UX) estilo aplicación web/SaaS para optimizar la navegabilidad ejecutiva.

## 🛠️ Stack y Metodología
* **Power Query:** Limpieza e ingeniería de datos, corrección de codificación de caracteres (encoding), eliminación de duplicados y estandarización de tipos.
* **DAX:** Modelo de datos optimizado con tabla de medidas dedicada (`_Medidas`) para calcular KPIs dinámicos (`Promedio Valoración`, `Promedio Jugabilidad`, `Promedio Duración`, `Promedio Innovación` y `Total Videojuegos`).
* **Power BI UI/UX:** Maquetación moderna con paleta de colores cobalto/navy, tarjetas redondeadas flotantes con sombras suaves y botones de filtrado interactivo lateral.

## 📊 Hallazgos Clave (Data Insights)
1. **Predominio de la Jugabilidad:** Los juegos con mayores puntuaciones de satisfacción usuario destacan principalmente por índices de jugabilidad elevados, demostrando ser un factor de mayor peso que el apartado gráfico.
2. **Independencia Gráfica:** Títulos con calidad gráfica categorizada en *Medio* o *Bajo* mantienen promedios de valoración altamente competitivos, respaldando la hipótesis de que la experiencia del usuario no depende únicamente del renderizado gráfico.
